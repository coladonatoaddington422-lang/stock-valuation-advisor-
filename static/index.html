      DCF / NAV 使用教学

      以盐湖股份（000792）为例。以下初始值是教学假设，不是公司真实预测或目标价；请用最新年报、公告和项目数据替换。

      盐湖股份：钾肥 + 锂资源周期资源股

      一、DCF：现金流折现

      适用：现金流可预测的成熟业务或分部。周期资源项目需用商品价格中枢、多情景预测。不能用于现金流长期为负、经营模式剧烈变化或终值假设无法成立的公司。

      计算逻辑：逐年预测自由现金流并折现；终值 = 第 N 年现金流 × (1+永续增长率) ÷ (折现率−永续增长率)；企业价值 = 显性期现金流现值 + 终值现值；股权价值 = 企业价值 + 净现金；每股价值 = 股权价值 ÷ 总股本。

      二、NAV：资源资产净值

      适用：矿产、油气、盐湖等资源资产，可拆分项目估值。不能只用资源量乘商品价格；必须考虑可采比例、品位、开发成本、税费、资本开支、项目进度、权益比例和折现。

      计算逻辑：钾肥项目净值 + 锂项目净值 + 其他资产净值 + 净现金 − 其他负债 = 股权 NAV；再除以总股本得到每股 NAV。这里的项目净值应是已经扣除项目开发成本、税费和风险折现后的价值。
      盐湖股份完整实务分析还必须拆分钾肥与锂业务的产能、产量、售价、单位成本、资本开支和权益比例，并做商品价格敏感性分析。上面的默认数字仅用于演示计算步骤，不能当作盐湖股份实际估值。
